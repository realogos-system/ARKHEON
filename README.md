# ARKHEON — Хроники Астерры

Технологически-магическая сборка Minecraft 1.21.1 с развитием от каменных инструментов до ядерной энергетики и космоса.

## Загрузка

Клиентский пакет будет опубликован в [Releases](https://github.com/realogos-system/ARKHEON/releases) после проверки подключения к серверу. Текущий релиз-кандидат загружен как черновик.

Пакет содержит моды, настройки, ресурспак русификации, путеводитель и официальный установщик NeoForge 21.1.262. Игровые миры, журналы и данные учётных записей в пакет не входят. Лаунчер пока не интегрирован с установкой клиента: этот архив предназначен для подготовки канала раздачи.

Сервер: `arkheon.minerent.io`, мир `AETHERRA`.

## Проверка целостности

Для каждой версии рядом с архивом публикуются `client-package.json` с SHA-256 и `launcher-client-manifest.json` со списком файлов. Лаунчер должен проверять манифест и SHA-256 до установки.
